| SQLite | Medición con y sin índice | No se hizo | `npm run bench` mide la ingesta y el resumen del mes, pero siempre con los índices puestos. |

| Redis | Al menos 3 estructuras distintas | No se hizo | Todo son strings: valores con vencimiento (`fx:…`, `tok:…`) y un contador con `INCR` (`rl:…`). Faltan otras dos estructuras, por ejemplo un hash o un sorted set. |
| Redis | Invalidación de caché | Parcial | Las claves vencen por TTL (6 horas el tipo de cambio, lo que le quede al token). No hay invalidación explícita cuando cambia el dato. |
| Redis | Medición con y sin caché | Hecho | [`docs/MEDICIONES.md`](../MEDICIONES.md): sin caché, mediana de 694 ms; con Redis, 2,0 ms; con caché en memoria, 0,8 ms. |
| Redis | Comportamiento si Redis cae | Hecho | Caché en memoria del proceso; probado cortando Redis a mitad de la prueba (`server/test/adapters/outages.test.js`). |
| MongoDB | Índices y `explain()` | Parcial | Índices `{ userId, kind, id }` (único) y `{ userId, serverSequence }` (el cursor). Falta mostrar con `explain()` que la sincronización los usa. |
| MongoDB | Un aggregation pipeline o `$lookup` | No se hizo | El servidor nunca cruza datos (los totales se calculan en el teléfono). Falta uno con sentido, por ejemplo el resumen de lo respaldado por tipo de registro. |
| MongoDB | Medición de una consulta representativa | No se hizo | Se puede hacer con `npm run seed:mongo`, que carga datos reproducibles. |

## 6. Decisiones técnicas tomadas

- **El landing es un sitio aparte** (`landing/`), sin código compartido con la app. Así la app no carga Three.js ni las animaciones, y el landing se compila y se publica por su cuenta.
- **Landing y app en hostnames distintos** (`movocr.xyz` y `app.movocr.xyz`), servidos por el mismo Nginx del VPS. La app conserva su propio origen para el inicio de sesión de Google y el service worker.
- **La guardia de privacidad también cubre la infraestructura:** además de datos personales, rechaza IPs de servidores y hostnames de sslip.io o nip.io, para que el repositorio público no revele la dirección del VPS.
- **La lectura de Gmail recuerda con qué búsqueda leyó** (`last_scan_query`). Si cambia, vuelve a revisar 45 días; los correos ya leídos no se descargan otra vez.
- **El modo demo conserva su simulador de banco.** Se quitó del README en [#89](https://github.com/jbrown230/Movo/pull/89) y se volvió a poner, porque el modo demo sí lo tiene.
- **`v0.9.0` y no `v1.0.0`:** el release candidate está desplegado y usable, pero faltan los puntos del enunciado de la sección 4.
